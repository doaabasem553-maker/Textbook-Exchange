# Used Textbook Marketplace — User Stories

## Epic 1: Account Management

**US-01: User Registration**  
As a student, I want to create an account so that I can access the marketplace.

**US-02: User Login**  
As a registered student, I want to log in so that I can access my account.

**US-03: Manage Profile**  
As a student, I want to update my profile information so that my account details remain accurate.

## Epic 2: Browse & Search Books

**US-04: Browse Available Books**  
As a buyer, I want to browse available textbooks so that I can discover books to purchase.

**US-05: Search for Books**  
As a buyer, I want to search for textbooks by title or author so that I can find a specific book.

**US-06: Filter Books**  
As a buyer, I want to filter books by subject and price so that I can find books matching my preferences.

## Epic 3: Book Listings

**US-07: View Book Details**  
As a buyer, I want to view a book's details so that I can evaluate it before purchasing.

**US-08: Create Book Listing**  
As a seller, I want to list a textbook with its title, price, condition, and photo so that buyers can find it.

**US-09: Manage Book Listings**  
As a seller, I want to edit or remove my listings so that I can keep my available books updated.

## Epic 4: Checkout & Payment

**US-10: Add Book to Cart**  
As a buyer, I want to add textbooks to my shopping cart so that I can purchase them together.

**US-11: Checkout**  
As a buyer, I want to enter my delivery information so that my purchased books can be shipped to me.

**US-12: Online Payment**  
As a buyer, I want to pay online so that I can complete my textbook purchase.

## Epic 5: Orders & Delivery

**US-13: View Orders**  
As a buyer, I want to view my orders so that I can monitor my purchases.

**US-14: Manage Sales Orders**  
As a seller, I want to view and manage incoming orders so that I can prepare books for delivery.

**US-15: Update Delivery Status**  
As a seller, I want to update an order's delivery status so that buyers know the progress of their shipment.
