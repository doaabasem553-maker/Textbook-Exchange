## Important: Jira screenshot
The assignment asks for a screenshot of the Jira backlog showing at least 12 stories with story points. A real screenshot must be taken from your own Jira project after importing/creating these issues. It cannot be generated honestly from outside your Jira account.

## Jira import
In Jira, use the CSV import option (if available in your project/settings), map:
- `Issue Type` -> Issue Type
- `Summary` -> Summary
- `Description` -> Description
- `Story Points` -> Story Points

If your Jira setup does not allow CSV import, create the 15 issues manually using the same values in `jira-import.csv`.

After import, open the Backlog, make sure the Story Points column is visible, and save a screenshot as `jira-backlog.png` in this folder.

Before submitting, confirm your team agrees with the story scope, estimates and MVP line. The velocity and sprint duration in `forecast.md` are planning assumptions.
